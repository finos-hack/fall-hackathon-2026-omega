# Submission

- **Project:** Governance-as-Code Evidence Workbook: traces FINOS CALM controls to FINOS AI Governance Framework (AIGF) risks, flags gaps and unsupported claims, and exports an auditor-ready Excel workbook with a CI gate.

- **Track:** Track 2 – Extend & Utilize FINOS Governance-as-Code

- **Team:** solo – Jiaxing (Chris) Xue (@jiaxingxue); repo: https://github.com/finos-hack/fall-hackathon-2026-omega

- **Repo history:** Developed in github.com/jiaxingxue/gac-evidence-workbook and moved to this official repo on Nov 18.

- **Why FINOS should care:** Auditors and second-line risk teams need risk → control → evidence traceability in a form they can review and sign off, but Governance-as-Code lives in JSON. Run against the FINOS Steel Thread, the tool found real, actionable issues:
  - two UC-3 risks no control claims: ri-17 Lack of Explainability, and ri-19 Data Quality and Drift (which AIGF says the already-used mi-4 covers);
  - one claim the AIGF catalogue doesn't support (mi-11 → ri-1).

  Path to graduation:
  1. Upstream an xlsx/report output to CALM tooling (for example a `calm docify` option).
  2. Package the AIGF claim-consistency check as a reusable CI action.
  3. Verify runtime evidence from the Steel Thread (metrics and tests) instead of declared evidence only.

- **Repo state:**
  - `src/gac_workbook/`: `calm.py` (CALM 1.2 loader), `aigf.py` (AIGF snapshot), `coverage.py` (expected vs claimed vs catalogue-implied, findings with recommended actions), `workbook.py` (Excel and Markdown), `cli.py` (`check`, `export`)
  - `data/aigf-snapshot.json`: AIGF IDs, titles, status and links @ `67b8c32` (© FINOS, CC-BY-4.0), generated by `scripts/build_aigf_snapshot.py`
  - `tests/`: pytest with synthetic fixtures; Steel Thread checks are skipped when its clone is absent
  - `.github/workflows/governance-check.yml`: `tests` job, plus `steel-thread-check` (calm validate → export → check; the workbook is uploaded as an artifact)
  - `docs/`: data sources and pinned SHAs, design decisions, CALM validation baseline, upstream license request draft

- **Validation:**
  - pytest: `52 passed` locally on Python 3.14.7 and 3.10.8; CI `tests` job passed on Python 3.10 and 3.13
  - `calm validate` (`@finos/calm-cli` 1.73.0) on the Steel Thread @ `2782173`: 0 errors, 0 warnings (local and CI)
  - `gac-workbook check` on the Steel Thread: `Coverage result: GAPS FOUND (2 errors, 2 warnings)`, exit 1
    - ERROR GAP ri-17 (Lack of Explainability). AIGF candidate: mi-13
    - ERROR GAP ri-19 (Data Quality and Drift)
    - WARNING POSSIBLY COVERED, NOT CLAIMED: ri-19 via mi-4
    - WARNING UNSUPPORTED CLAIM: `human-feedback-loop` mi-11 → ri-1
    - INFO DRAFT REFERENCE: uc-3 Loan Approval is Draft in AIGF
